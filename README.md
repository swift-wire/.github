# .github

Organisation-wide defaults for the wire family.

GitHub serves the files here for any repository in the `swift-wire` organisation that does not
carry its own copy, so `CONTRIBUTING.md` is the single governing document for all of them. A
repository that needs to say something specific — how to build it, which gates it has — carries its
own `CONTRIBUTING.md`, which GitHub then serves instead; those files add to this one rather than
replacing it, and say so.

Changing the policy here changes it for every repository at once, so it goes through the same
review as anything else.
